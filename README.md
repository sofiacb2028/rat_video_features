# Quantifying Sleep Status in Rats

This repository contains scripts and preliminary results for processing videos of rats and extracting motion features to determine consciousness, inspired by the noninvasive sleep assessment paper (PMC8842275).

## Contents
- scripts/analyze_features.py: plots rat movement over time and outputs to image
- scripts/detect_moving_rat_configurable.py: Employs background segmentation to extract rat features and outputs data to csv and video files
